## Overview

Bleap is a focused AU/VST sound-design plugin for rapid SFX creation:
risers, impacts, downlifters, sweeps, and transitional textures.

## Core Signal Chain
`Oscillator + Noise -> Mixer -> Filter -> Amp/Env -> FX -> Output`

## Key Systems
- Global Sync/Free timing mode
- Three one-shot modulation slots
- Macro control for DAW automation workflows
- Full random and wiggle randomization
