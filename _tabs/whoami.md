## Whoami

I am Charles Lewis, a security and infrastructure professional building music
tools under the NOPHASE project.

NOPHASE.CC is the public home for those tools: plugins, Max devices, MIDI
utilities, and odd experiments built around unpredictability, texture, and
workflow-first sound design.

The project is not chasing pristine perfection. The goal is to make software
that invites happy accidents, unstable motion, and strong character without
burying the creative process under menus and setup friction.

My background combines:
- Security operations and DDoS mitigation
- IT administration and web systems
- Audio production and sound design
- Plugin and tool development with C++ and JUCE

NOPHASE is where those disciplines meet: practical software for producers,
artists, and workflow-focused creators.

## Current Focus

- JUCE plugins with custom UI and fast exploratory workflows
- Max for Live and MIDI utilities for performance and studio use
- Tools that balance controlled modulation with deliberate unpredictability
