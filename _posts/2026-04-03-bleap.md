## Summary
Bleap is a purpose-built AU/VST plugin for quick creation of risers, impacts,
noise sweeps, downlifters, whooshes, and transition FX.

## Status
Prototype underway.

## Format
- JUCE sound-design plugin
- Formats currently building: VST3, AU, and Standalone
- Focused on production SFX creation instead of general-purpose synthesis
- Uses a custom modulation and randomization workflow for fast iteration

## Core System
- Oscillator plus dedicated noise generator
- Filter and envelope shaping
- FX chain for reverb, delay, distortion, flanger, ring mod, and width
- Built-in one-shot modulation slots (no complex matrix required)
- Global Sync/Free timing mode for DAW-locked or free-time workflows

## Workflow Features
- Macro control for automation performance
- Full random plus wiggle randomization modes
- Preset categories focused on production SFX use cases
